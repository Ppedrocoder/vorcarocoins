# VorcaroCoins (React + Django Ninja)

Jogo fictício: o usuário começa com 134.000 vorcarocoins e aposta tudo em Lula ou Flávio Bolsonaro (2º turno, 25/10/2026). Quem acerta recebe o dobro e a insígnia Eleitor Master.

## Backend

- Entre na pasta backend com `cd .\backend`
- Rode o comando `pip install -r requirements.txt`
- Crie a .env dentro da pasta backend baseado na .env.example
- Rode o comando `python manage.py makemigrations`
- Rode o comando `python manage.py migrate`
- Rode o comando `python manage.py runserver`

## Frontend

- Entre na pasta frontend com `cd .\frontend`
- Rode o comando `npm install`
- Crie a .env dentro da pasta frontend baseado na .env.example
- Rode o comando `npm run dev`
